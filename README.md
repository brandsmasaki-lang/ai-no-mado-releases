# AIのまど

AIのまどのアプリと更新版を配布するページです。ソースコードは公開していません。

アプリは無料で配布します。利用にはAIのたねへの会員登録・ログインが必要です。ダウンロードできることと、認証済みで利用できることは別です。

## ダウンロード

検証を終えたアプリを、このリポジトリの[Releases](https://github.com/brandsmasaki-lang/ai-no-mado-releases/releases)へ掲載します。現在は一般配布物を準備中です。掲載前の検証版を完成版として配布しません。

## 更新

1. AIのまどで実行中の作業を終え、アプリを終了します。Macでは⌘Qで終了してください。
2. [Releases](https://github.com/brandsmasaki-lang/ai-no-mado-releases/releases)から、掲載済みの対応OSの最新版と案内を確認してください。
3. その版の案内に従って更新し、AIのまどを開き直してください。会話・成果物・認証の保存フォルダは削除しないでください。

このページを開くだけではアプリは更新されません。GitHubアカウントや招待はダウンロードの条件ではありません。

## ログインできない場合

まず利用中の版と掲載済みの最新版を確認してください。更新済みでも解消しない場合は、アプリのバージョンと表示されたメッセージを案内元へお知らせください。パスワード・認証コード・トークンを送る必要はありません。
